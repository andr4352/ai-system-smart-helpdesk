# ADR-03 Модульный монолит

- Дата: 20.09.2026
- Статус: принято для проекта
- Контекст: Проект разрабатывает один студент. Модель небольшая и работает на CPU.
- Решение: Разместить API, модель и правила в одном Docker-контейнере, разделив код на модули.
- Обоснование: Монолит проще запускать и отлаживать. Микросервисы добавили бы сетевые вызовы и отдельные настройки развертывания.
- Последствия: Все модули выпускаются вместе. SQLite ограничивает параллельную запись; при заметном росте нагрузки сначала перейти на PostgreSQL, затем при необходимости выделить инференс.
