# Учебные данные

demo_train.csv содержит 64 искусственно составленных обращения: по 16 на ACCOUNT, STUDY, PAYMENT, OTHER. Персональных сведений нет. Это небольшой демонстрационный набор, а не выгрузка из университета.

Примеры в app/demo.py и тестах написаны отдельно; они проверяют работу компонента, но не являются независимой оценкой точности на реальных заявках. Полноценное разделение train/validation/test, расширение набора и проверка порога 0.8 остаются для следующих работ. Параметры модели фиксированы заранее; подбор по демонстрационным примерам не выполняется.
